## 先上配置

打开图吧工具箱，家底一目了然：

| 部件 | 型号 | 点评 |
| ---- | ---- | ---- |
| 处理器 | Xeon E5-2678 v3（十二核） | 2014 年的服务器 U，洋垃圾之王 |
| 主板 | 精粤 X99-TI D3 PLUS | 国产魔改板，专治洋垃圾 |
| 内存 | 32GB DDR3 1600MHz（8G×4） | 四根服务器拆机条，插满的快乐 |
| 显卡 | GTX 1060 6GB（七彩虹） | 一代神卡，至今不肯退役 |
| 固态 | 金士顿 1TB NVMe | 系统盘，性能够用 |
| 机械 | 西数 1TB + 建兴 128GB | 老三样，仓鼠症仓库 |
| 显示器 | 华硕 TUF VG27A（27 英寸高刷） | 全桌最贵的单品 |

是的，你没看错：**这套主机的二手行情，大概和这台显示器差不多一个价。**

## 为什么是洋垃圾

道理很简单：预算有限的时候，钱要花在体验上，而不是参数上。

CPU 和显卡的性能是"过剩感知"——从 1060 升级到 4060，跑分翻倍，但打 CS2 的帧数早都够用了；而从一个 60Hz 的普通屏换到 27 寸高刷，是每天开机都能感受到的差别。所以我选择了：**计算性能用二手市场贬值来换，显示体验用真金白银来换。**

E5-2678 v3 十二核在此还有个隐藏福利：多开。游戏挂着、虚拟机开着、浏览器几十个标签，它面不改色——毕竟人家当年是给机房 7×24 干活的。

> [!TIP]
> 洋垃圾的正确打开方式：接受它单核弱的事实，把吃单核的任务让给别人的电脑，把吃多核和内存的任务留给自己。

## 1060 的晚年生活

 GTX 1060 6GB 是这个平台上最有故事感的部件。它现在的日常工作：

- **CS2**：745 小时里大部分是它扛下来的，1060 打 CS2 绰绰有余
- **赛博朋克 2077**：中画质，夜之城的夜景依然震撼——画质党会皱眉，但我玩得津津有味
- **越来越黑暗**：地牢里帧数稳定，配合加速器体验良好
- **Blender / OBS**：偶尔渲染和录屏，十二核 + 32G 内存这时候才显出价值

## 手机这边

手机是 vivo（OriginOS），几个值得一提的细节：

1. **红外遥控**——十月了空调还在制冷，遥控器？不存在的，手机贴脸开大
2. **双加速器**（UU + 雷神）——Dark and Darker 玩家的自我修养
3. **IGXE**——CS 饰品交易平台。结合上次 Steam 库里 745 小时的 CS2，这条产业链已经闭环了
4. **闲鱼 + 转转**——这台主机的零部件，大概率就是从这两个 App 里流进来的
5. 工具文件夹里躺着 GitHub、MT管理器之类的玩意——手机也不想让它安分

## 垃圾佬的快乐

这套设备的哲学，总结起来就一句话：

> 它不需要是新的，它只需要能干活。

十年前的 U、六年前的显卡、拆机内存条，组合在一起依然能扛住 2341 小时的游戏时长、偶尔的渲染任务和每天十几个小时的亮屏。每次图吧工具箱跑完分，我都觉得这钱花得像诈骗——不过是反向诈骗，是平台和二手商贩被我诈骗。
